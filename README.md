# INF — материалы к занятиям по информатике

Открыть онлайн: [https://aumphaadr.github.io/INF/](https://aumphaadr.github.io/INF/)

Учебный сайт: интерактивные инструменты к урокам, по странице на урок.
Не тезисы, а вещи, которые можно покрутить руками.

## Запуск

Статика без сборки и зависимостей. Нужен любой http-сервер — из-под
`file://` ES-модули не грузятся.

```
npm run serve        # python3 -m http.server 8080
npm run check        # самопроверка модели систем счисления в node
```

## Уроки

**Системы счисления** — `numeral-systems.html`.

* Составитель чисел: пять разрядов-барабанов, у каждого своё колесо
  цифр. Щелчок — следующая цифра, правый щелчок или колесо мыши —
  предыдущая, с клавиатуры — стрелки и сами цифры. Барабан крутится
  по кругу без переноса: так видно алфавит системы. Кнопки «+1» / «−1»
  считают с переносом: так видно счёт. Разряд, у которого кончились
  цифры, вспыхивает; переполнение пяти разрядов вспыхивает рамкой.
* Один составитель для десятичной, один для пятеричной, потом все девять
  от двоичной до десятичной. Компонент один и тот же — в этом и урок.
* Переключатель «вес разрядов» открывает под барабанами степени
  основания и разложение числа по весам с десятичным значением.
  По умолчанию выключен: учитель включает, когда класс готов.
* Сравнительная таблица: строка — число, столбец — система. Десятичный
  столбец слегка подсвечен как привычный. Круглые числа каждой системы
  (10, 100, 1000 в её записи) выделены. Столбцы включаются и выключаются
  чипами (десятичный не выключается: он точка опоры), есть «все» и
  «только десятичная». Строка закрепляется щелчком,
  порядок столбцов переворачивается, раскраска по числу разрядов
  показывает диагональные полосы — одну и ту же лестницу, но своим шагом
  в каждой системе.
* Ползунок «одно число — разные основания»: число стоит, основание
  едет, запись перестраивается на глазах, под разрядами — веса.

Модель (`js/numerals.js`) знает основания до 36: расширение урока
на шестнадцатеричную — правка констант в `js/lesson-numeral-systems.js`.

**Перевод между системами** — `base-conversion.html`. Без остатков от
деления: разбивка на слагаемые, перевод каждого, сложение.

* Столбик степеней с выбором основания: степень, её десятичное значение
  и её запись в системе — единица и n нулей.
* Из десятичной: рабочий лист в три действия. Разбивка — на каждом
  шаге самая большая степень, которая влезает в остаток; ученик сам
  щёлкает её в столбике, столбик отвечает вспышкой: зелёной — верно,
  красной — не влезает, янтарной — влезает, но есть побольше. Затем
  перевод каждого слагаемого по столбику и сложение столбиком без
  переносов. «Шаг» делает ход за ученика, «Всё» проходит лист до конца.
* В десятичную: зеркально. Разбивка записи по разрядам, поиск степени
  каждого слагаемого в столбике, сложение в десятичной.
* Результат одного переводчика одной кнопкой уходит на вход другому.

**Системы от 11-чной до 16-чной** — `bases-11-16.html`. Продолжение
первого урока туда, где цифр не хватает.

* Алфавиты систем от двоичной до шестнадцатеричной: у каждой ровно
  столько цифр, каково основание; буквы A…F подсвечены, под каждой её
  значение. Ряд непрерывен, шестнадцатеричная в нём не особенная.
* Составитель для одиннадцатеричной и сетка от 11 до 16 — те же барабаны,
  буквы набираются и с клавиатуры. В разложении по весам цифра пишется
  числом: 15·16, а не F·16.
* Сравнительная таблица с десятичной и 11…16; двоичная и восьмеричная
  есть, но выключены до разговора о группах разрядов.
* Ползунок основания от 2 до 16.
* По две, три и четыре двоичные цифры: составители для оснований 4, 8
  и 16 показывают под каждым разрядом его двоичную группу и собирают
  двоичную запись без вычислений. Десятичная так не умеет — 10 не
  степень двойки; отсюда место восьмеричной и шестнадцатеричной.
* Цвет в шестнадцатеричной: три байта-составителя, образец цвета
  и запись вида #FFC456 рядом с rgb(255, 196, 86).

## Устройство

```
index.html                    главная: карточки уроков
numeral-systems.html          урок «Системы счисления»: разметка разделов
favicon.svg
css/tokens.css                палитра
css/style.css
js/nav.js                     боковое меню, список уроков
js/home.js
js/numerals.js                модель систем счисления, без DOM
js/composer.js                составитель чисел
js/basetable.js               сравнительная таблица
js/baseslider.js              одно число — разные основания
js/lesson-numeral-systems.js  монтаж инструментов урока
base-conversion.html          урок «Перевод между системами»
js/convert.js                 модель перевода: столбик, разбивка, разбор записи
js/ladder.js                  столбик степеней
js/converter.js               переводчики в обе стороны, рабочий лист
js/lesson-base-conversion.js  монтаж инструментов урока
bases-11-16.html              урок «Системы от 11-чной до 16-чной»
js/alphabets.js               таблица алфавитов
js/colormix.js                цвет из трёх байтов
js/lesson-bases-11-16.js      монтаж инструментов урока
js/page.js                    общее для страниц уроков: монтаж, переключатель весов
tools/selfcheck.mjs           самопроверка моделей
.github/workflows/ci.yml      самопроверка в GitHub Actions при каждом пуше
LICENSE, LICENSE_RU.md        лицензия MIT и её перевод
THIRD-PARTY-NOTICES.md        сторонние компоненты (сейчас их нет)
CONTRIBUTING.md               правила для правок и новых уроков
CHANGELOG.md                  история изменений
```

Новый урок — новая страница `<slug>.html` со своей разметкой, свой
`js/lesson-<slug>.js` с монтажом и строка в `LESSONS` в `js/nav.js`.
Инструменты у уроков разные, общего у них только каркас: шапка, меню,
токены и базовые контролы (`.tools`, `.chk`, `.seg`, `.act`). Полный
порядок и правила — в [CONTRIBUTING.md](CONTRIBUTING.md).
