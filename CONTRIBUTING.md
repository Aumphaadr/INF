# Правки и новые уроки

Самый полезный вклад в INF — сообщение об ошибке: неверное число в таблице,
кнопка, которая ведёт себя не так, неточная подпись.
[Заведите issue](https://github.com/Aumphaadr/INF/issues/new): на какой странице
и в каком разделе, что сделали, что увидели и что ожидали увидеть.

Правки принимаются на условиях лицензии проекта — [MIT](LICENSE).

## Как устроен урок

Урок — отдельная страница со своими инструментами. Общего у уроков только каркас:
шапка, боковое меню, палитра и базовые контролы (`.tools`, `.chk`, `.seg`, `.act`).

1. Страница `<slug>.html` — разметка разделов с местами монтажа `data-mount`.
2. Сценарий `js/lesson-<slug>.js` — монтаж инструментов на эти места.
3. Модель — чистые функции без DOM в отдельном модуле, как `js/numerals.js`;
   её проверки — в `tools/selfcheck.mjs`.
4. Строка в списке `LESSONS` в `js/nav.js` и карточка на `index.html`.
5. Раздел урока в [README.md](README.md) и строка в [CHANGELOG.md](CHANGELOG.md)
   в разделе «Не опубликовано».

## Проверка перед публикацией

- `npm run check` проходит без строк «ПРОВАЛ».
- Страницы открыты через http-сервер (`npm run serve`), а не с диска:
  из-под `file://` ES-модули не грузятся.
- Каждый инструмент проверен на широком экране и на ширине телефона, около 400 px.
- В консоли браузера нет ошибок.

## Правила

- **Статика без сборки и зависимостей.** JavaScript в ES-модулях, CSS и SVG,
  без библиотек и без CDN: всё, что нужно странице, лежит в репозитории.
- **Числа не врут.** Таблицы, разложения и переводы считает модель, примеры
  в подписях сверяются с ней.
- **На сайте — инструменты и короткие подписи к ним.** Рассказ ведёт учитель
  на уроке. Раскрытия вроде «веса разрядов» по умолчанию выключены: их включает
  учитель, когда класс готов.
- **В примерах кода — полная форма `x = x + 1`**, а не `x += 1`.

## Чужие файлы

Всё, что не создано для проекта, — шрифт, картинка, звук, библиотека, набор
данных — добавляется, только если:

1. лицензия разрешает свободное использование, в том числе в образовательных
   организациях и коммерческих продуктах;
2. текст лицензии лежит рядом с файлом — для шрифта это `Имя-OFL.txt` в той же
   папке;
3. в [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md) появилась строка: что это,
   откуда, кто автор, какая лицензия и где файл лежит.

Шрифты подключаются своими файлами из репозитория, не с чужих серверов.

Значки берутся из набора [Klaarheid Icons](https://aumphaadr.github.io/Klaarheid-Icons/)
(MIT-0). Перед тем как взять значок, проверьте список совпадений с Lucide
и Tabler Icons в [THIRD-PARTY-NOTICES набора](https://github.com/Aumphaadr/Klaarheid-Icons/blob/main/THIRD-PARTY-NOTICES.md).
Если значок там есть, вместе с ним в THIRD-PARTY-NOTICES.md INF переносятся
сноска и текст лицензии Lucide (ISC) или Tabler Icons (MIT).

Тексты и задания — свои. Условия задач, таблицы и иллюстрации из учебников,
экзаменационных материалов ФИПИ и чужих сайтов не копируются. Сослаться на тип
экзаменационного задания можно, но условие и числа придумываются заново.
