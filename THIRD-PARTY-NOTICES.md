# Сторонние компоненты и их лицензии

INF распространяется по лицензии [MIT](LICENSE). Сторонних компонентов в проекте
нет: всё, что лежит в репозитории, создано для него. Ниже по разделам — чем сайт
пользуется и откуда это берётся.

## Шрифты

Файлов шрифтов в проекте нет. Текст рисуют шрифты, установленные на компьютере
зрителя: в `css/tokens.css` записаны только их имена — `system-ui`, Segoe UI,
Liberation Sans и Arial для интерфейса, `ui-monospace`, JetBrains Mono,
DejaVu Sans Mono, Liberation Mono и Consolas для чисел. Браузер берёт первый
из найденных. Значок вкладки `favicon.svg` пишет «10» и «2» так же —
моноширинным шрифтом зрителя.

## Значки

Файлов значков в проекте нет, кроме значка вкладки `favicon.svg`, созданного
для проекта. Кнопка меню, стрелки, галочка и крестик — символы Юникода
(☰, →, ↑, ↓, ✓, ×); их рисует шрифт зрителя.

## Библиотеки

Нет. Сайт написан на JavaScript без библиотек: в `package.json` нет
ни `dependencies`, ни `devDependencies`, `npm` только запускает скрипты.
Локальный сервер `npm run serve` — модуль `http.server` из стандартной
библиотеки Python; с проектом он не распространяется.

## Код, тексты и изображения

Код инструментов и моделей, подписи, таблицы и значок вкладки созданы для INF
и распространяются по лицензии проекта (MIT). Код и подписи написаны с Claude —
ИИ-ассистентом Anthropic — по методике и под руководством автора. Цитат
из учебников, заданий из экзаменационных материалов и чужих иллюстраций
на сайте нет.

## Если здесь что-то появится

Сторонний файл добавляется только вместе со своей лицензией и строкой в этот
файл: что это, откуда, кто автор, какая лицензия и где файл лежит. Порядок —
в [CONTRIBUTING.md](CONTRIBUTING.md#чужие-файлы).
